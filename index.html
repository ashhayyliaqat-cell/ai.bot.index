About Pakistan AI

Built around one idea.

The AI is the primary feature. The rest of the website simply gives visitors a visual, structured way to discover Pakistan.

Direct answers

The system prompt tells Gemini to answer the user's exact question first instead of dumping a generic paragraph about Pakistan.

Multilingual

Questions can be asked in English, Urdu, Roman Urdu or mixed Urdu-English, with the response matching the user's language.

Conversation memory

Recent turns are sent with each request so follow-up words such as “its”, “there” or “he” can be interpreted in context.

Secure by design

The browser never receives the Gemini API key. The key exists only as a Netlify Function environment variable.
